# Lanzador 152–202 (GitHub Actions + Node.js)

Este módulo pertenece al repositorio **control-linux existente**. No crea repositorios, no altera proyectos archivados y nunca fuerza fusiones o resetea ramas.

## Requisitos operativos

El repositorio tiene que disponer de un secreto Actions denominado `RELEASE_TOKEN` con permisos limitados de lectura de repositorios privados, lectura de CI y escritura de pull requests **solo** sobre los repositorios que el usuario autorice. Nunca poner el token en un archivo, commit o mensaje. Los permisos habituales del `GITHUB_TOKEN` de un repositorio no sirven para operar indiscriminadamente sobre otros repos privados.

```bash
node --test tests/release-batch-152-202.test.mjs
# Vista de estado, sin cambios de producción:
RELEASE_TOKEN=... node scripts/release-batch-152-202.mjs
# Solo PRs propietarios release/2026-10-21-*, con CI verde y mergeable:
RELEASE_TOKEN=... node scripts/release-batch-152-202.mjs --merge-ready
```

`out/batch-152-202.json` conserva los resultados observados. No hay publicación si GitHub devuelve checks vacíos, pendientes, fallidos, un PR de un fork, un PR borrador o una rama fuera del lote. Los historiales se fusionan con método `merge`, sin hacer `force-push`. El despliegue posterior **solo sucede** si el proyecto ya tiene Git conectado a su plataforma de hosting; este script no inventa dominios ni promete despliegues.

## Ejecución automática

GitHub Actions está configurado para evaluar el lote diariamente y, si está habilitado `RELEASE_TOKEN`, fusionar exclusivamente los PR que cumplan las garantías. Por defecto, una ejecución manual muestra resultados sin publicar, salvo que se seleccione `merge_ready`. El flujo no equivale a crear agentes autónomos residentes en Linux ni verifica automáticamente el contenido humano: necesita la CI real de cada proyecto, secretos y aprobación de accesos. Si Actions carece de minutos, está bloqueado o la ejecución falla, la máquina **no publica**.

Las versiones archivadas no se desarchivan, eliminan, mezclan ni reescriben. Los repos activos sin un PR específico permanecen intactos hasta completar sus productos.
